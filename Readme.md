## How to contribute

### Step 1: Become a collaborator

Contact [@IveGotMagicBean](https://github.com/IveGotMagicBean) with your GitHub username. Once you’re added, you can push directly to this repository.

### Step 2: Clone the repo

```bash
git clone git@github.com:IveGotMagicBean/BioClaw-Page.git
cd BioClaw-Page
```

### Step 3: Edit and push

```bash
# Edit index.html or other files
git add .
git commit -m "Describe your changes"
git push
```

After you push, GitHub Pages usually updates the site within one to two minutes.
